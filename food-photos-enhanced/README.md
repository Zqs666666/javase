## `美食风/`（推荐分享）
偏美食摄影风格：更暖、更通透、色彩更有食欲。适合发朋友圈 / 小红书。

## `高清调色/`
基于原图像素的高清调色版（去雾、白平衡、饱和、对比、锐化、高光压制），分辨率更高，细节更接近原图。

处理要点：暖色食欲向白平衡、局部清晰度、食物色相选择性提饱和、油光高光回收、锅中蒸汽雾感减弱。
